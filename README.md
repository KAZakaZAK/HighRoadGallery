# High Road Gallery proof of concept

Static multi-page preview of the redesign. Plain HTML, CSS and vanilla JS. No build step needed to view it.

Live: https://kazakazak.github.io/HighRoadGallery/

## Structure

```
index.html ... press.html   11 pages, generated by tools/build.py
assets/css/tokens.css        design tokens (mirror the Figma variables)
assets/css/styles.css        layout and components
assets/js/main.js            menu drawer, demo forms, donate amounts, calendar download
assets/icons/                PWA icons
docs/design-tokens.json      token export
sw.js, manifest.webmanifest  offline support
tools/build.py               regenerates every page
```

## Editing

Shared header, menu, footer and sticky CTA live in `tools/build.py`. Change them once, then run:

```
python3 tools/build.py
```

Commit the regenerated `.html` files. Bump `CACHE` in `sw.js` when assets change.

## Preview behavior

Forms validate and confirm on the page. Nothing is sent. Donate amounts and Add to calendar are demos. Image and map areas are placeholders.

## Deploy

GitHub Pages: Settings, Pages, deploy from branch `main`, folder `/ (root)`. `.nojekyll` is included.
